# Trazabilidad institucional

Se conservan íntegros los documentos aportados en REGLAS_MAESTRAS.md e INSTRUCCIONES_DESARROLLO.md. Esta tabla identifica implementación y diferimiento, sin sustituir el texto original ni declarar conformidad institucional completa.

| Decisiones | Aplicación actual | Estado |
|---|---|---|
| DEC-001 | Entidades de indicador, método, fuente, ejecución, resultados, tableros, cuentas y auditoría | Núcleo parcial implementado |
| DEC-002 | Sin catálogo precargado; creación no aprueba metodología ni publicación | Principio aplicado; tipología institucional futura |
| DEC-003 | Cuentas autorizadas, roles técnicos y alcances | Parcial; áreas/operadoras/externos formalizados después |
| DEC-004 | API de datos exige sesión; no hay portal público | Aplicado al núcleo local |
| DEC-005 | RBAC y alcance por indicador/fuente, también en exportaciones y tableros | Aplicado al núcleo local |
| DEC-006 | Solo admin gestiona cuentas; editores crean/modifican objetos autorizados | Delegación técnica básica; gobernanza futura |
| DEC-007, DEC-008, DEC-009 | No se concede autoridad metodológica por tener rol técnico admin | Coordinación/facultades y consultas especializadas diferidas |
| DEC-010, DEC-011, DEC-012, DEC-013 | No se sustituye criticidad por un semáforo único ni se asignan niveles ficticios | Diez dimensiones, escala y criterios diferidos |
| DEC-014, DEC-015, DEC-016, DEC-017, DEC-018 | No hay inferencia automática de autorización por cálculo | Perspectivas, base/contexto y activadores diferidos |
| DEC-019, DEC-020, DEC-021 | Ninguna ejecución concede autorización de uso | Flujos humanos y ocho clases especiales diferidos |
| DEC-022 | Resultados etiquetados provisionales, sin autorización | Aplicado a exploración sintética autorizada |
| DEC-023 | Método, resultado y autorización son conceptos separados; borrador/provisional/ninguna | Núcleo aplicado; ciclos completos futuros |
| DEC-024, DEC-027 | Métodos inmutables desde su creación; nuevas versiones para cambios | Regla más conservadora en desarrollo; aprobaciones/editoriales futuras |
| DEC-025, DEC-029 | Métodos únicamente en borrador, sin endpoints de aprobación | Estados EM-02 a EM-12 diferidos |
| DEC-026, DEC-028, DEC-030 | No se implementan transiciones institucionales ad hoc | Flujos/revisión/desistimiento futuros |
| DEC-031 | Se conserva como decisión histórica enmendada por DEC-034 | No se restaura facultad de cierre unilateral |
| DEC-032 | Identidad estable independiente del nombre y del área; sin propiedad exclusiva de área | Principio aplicado |
| DEC-033 | Relación entre indicadores implementada; no representa participación de áreas | Participación individual por área diferida |
| DEC-034, DEC-035, DEC-036 | Desactivar es reversible y conserva el historial; no representa desistimiento | Autoridad central, verificación y expediente de cierre diferidos |
| DEC-037, DEC-038, DEC-039 | Reactivar no restaura aprobaciones ni representa reapertura EM | Continuidad/reapertura institucional diferidas |
| DEC-040, DEC-041, DEC-042 | No se simulan evidencias ni su validez | Revalidación, vigencia y diez categorías EV diferidas |
| DEC-043, DEC-044 | Auditoría técnica no se denomina motor institucional EVT | Dependencias/eventos y doce categorías diferidos |
| DEC-045 | CSV manual: responsable de carga, contenido inmutable, huella y nueva carga como alternativa | Cobertura básica; vigilancia externa futura |
| DEC-046, DEC-047 | Actor técnico identificado en auditoría | Funciones institucionales, titulares/suplentes y periodos diferidos |
| DEC-048, DEC-049, DEC-050, DEC-051 | No se confunde prioridad con criticidad ni se inventan plazos | Escalamiento, cuatro prioridades PO y matriz contextual diferidos |

DEC-052 no está aprobada. No se incorpora como requisito vigente. La ausencia de flujos avanzados no se oculta ni impide verificar el núcleo genérico con datos ficticios.
